# Markdown Lite | Taller práctico con GitHub Spec Kit y Codex

**De una idea a una aplicación mediante desarrollo guiado por especificaciones y herramientas de inteligencia artificial.**

Este repositorio recoge una experiencia práctica de desarrollo de software utilizando **GitHub Spec Kit y OpenAI Codex**, a través de la construcción de una aplicación experimental: **Markdown Lite**, un editor ligero de Markdown.

El taller nació como un ejercicio personal de aprendizaje y experimentación. No ha sido elaborado desde la perspectiva de un experto en GitHub Spec Kit, sino desde la de alguien interesado en conocer estas herramientas, ponerlas en práctica y comprender sus posibilidades y limitaciones.

La guía comparte el recorrido seguido, incluyendo los pasos realizados, las decisiones tomadas, las dificultades encontradas, los errores, las correcciones y los aprendizajes obtenidos.

No pretende ofrecer un procedimiento perfecto ni una referencia definitiva, sino compartir una experiencia real que pueda resultar útil a otras personas.

## 📘 La guía del taller

La guía recorre el proceso de desarrollo con GitHub Spec Kit y Codex, desde la preparación del entorno hasta la implementación y las pruebas de funcionalidades.

Se abordan, entre otros, los siguientes aspectos:

- Preparación del entorno y herramientas necesarias.
- Definición de principios y reglas del proyecto.
- Elaboración y refinamiento de especificaciones.
- Planificación técnica y descomposición en tareas.
- Análisis de consistencia entre artefactos.
- Implementación incremental con Codex.
- Pruebas, detección de errores y correcciones.
- Control de versiones y seguimiento del desarrollo.

El documento incluye explicaciones, instrucciones para reproducir los pasos, prompts utilizados, puntos de control y recomendaciones basadas en lo que se fue encontrando durante el piloto.

**La guía refleja el proceso tal y como se desarrolló**, con sus aciertos, dificultades y decisiones. Algunas de ellas podrían abordarse de otra manera y determinadas instrucciones pueden quedar desactualizadas conforme evolucionen las herramientas.

## 💻 Markdown Lite: el resultado del taller

Markdown Lite es un editor ligero de documentos Markdown, desarrollado como ejercicio práctico para experimentar con GitHub Spec Kit y Codex.

Su construcción sirve como hilo conductor del taller, permitiendo observar cómo evolucionan las especificaciones, las decisiones técnicas y las funcionalidades a medida que avanza el proyecto.

### Estado de la aplicación

**Markdown Lite es una aplicación experimental e inconclusa.**

No se trata de un producto terminado ni de una aplicación preparada para su utilización en entornos de producción. Es el resultado alcanzado durante el taller, cuyo objetivo principal era aprender y experimentar con el proceso de desarrollo.

La aplicación tiene aspectos pendientes de corrección y otros muchos susceptibles de mejora, tanto funcionales como relacionados con la experiencia de usuario, el diseño, la arquitectura, la calidad del código y las pruebas.

**Se ha conservado el archivo `index.html` como resultado del taller**, para que cualquier persona interesada pueda examinar la aplicación y conocer el resultado práctico del proceso descrito en la guía.

No se ha realizado un desarrollo adicional para convertirla en un producto terminado ni se pretende presentar como tal.

### 🚀 Descargar y probar Markdown Lite en local

**[Ver y descargar Markdown Lite — index.html](https://github.com/Kronvi/spec-kit-workshop-markdown-lite/blob/main/index.html)**

Para probar la aplicación:

1. Accede al archivo `index.html` desde el enlace anterior.
2. Pulsa **Download raw file** (icono de descarga) para guardarlo en tu equipo.
3. Abre el archivo descargado con tu navegador habitual (Chrome, Edge, Firefox, etc.).
4. Explora las funcionalidades del editor y comprueba el resultado obtenido durante el taller.

Si el HTML es autónomo y no necesita servicios externos ni recursos adicionales, no será necesario instalar dependencias ni configurar un servidor.

**Importante:** Markdown Lite es una aplicación experimental e inconclusa. Se comparte tal como quedó durante el taller, con errores pendientes de corregir y numerosas posibilidades de mejora.

Se recomienda utilizarla únicamente con fines de aprendizaje y experimentación, evitando trabajar con documentos importantes sin disponer de copias de seguridad.

## 🎯 ¿A quién va dirigido?

Este taller está pensado para desarrolladores, arquitectos de software, profesionales tecnológicos y cualquier persona interesada en conocer cómo aplicar herramientas de inteligencia artificial al proceso de desarrollo de aplicaciones.

No es necesario tener experiencia previa con GitHub Spec Kit o Codex, aunque resulta recomendable disponer de conocimientos básicos de programación, Git y herramientas de desarrollo.

La guía está planteada desde la perspectiva de alguien que aprende utilizando estas herramientas, por lo que puede resultar especialmente útil para quienes quieran realizar un recorrido similar.

## 💡 Más allá de los comandos

Una de las reflexiones que surgen durante el taller es que utilizar inteligencia artificial para desarrollar software no consiste únicamente en pedirle que genere código.

Definir correctamente lo que se necesita, revisar las decisiones, mantener la coherencia entre especificaciones y comprobar los resultados sigue siendo fundamental.

Por eso, además de explicar qué se hizo en cada paso, la guía incorpora observaciones sobre lo que sucedió durante el piloto y los aprendizajes obtenidos.

No se trata de presentar una metodología cerrada, sino de compartir una experiencia que otras personas puedan reproducir, cuestionar, mejorar o adaptar a sus propios proyectos.
